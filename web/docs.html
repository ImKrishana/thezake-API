The Zake API

A public HTTP API for poster extraction, direct-link resolution, title metadata, and platform discovery. All responses are JSON unless an HTML page is requested.

Base URLhttps://your-api.example.com
Quick start Poster API DDL bypass Metadata APIs Platform discovery Responses and errors

Quick start

Replace https://your-api.example.com with the deployed API base URL.

curl -G 'https://your-api.example.com/poster' \
  --data-urlencode 'url=https://www.playflix.app/content/MjAzMzg='

curl 'https://your-api.example.com/platforms'

The generic poster endpoint detects the platform from the submitted URL and chooses the correct scraper automatically.

Poster API

GET/poster

Automatically detect a supported platform and return its scraper response.

Query parameterRequiredDescription
urlYesComplete HTTP(S) content URL from a supported platform.
curl -G 'https://your-api.example.com/poster' \
  --data-urlencode 'url=https://www.playflix.app/content/MjAzMzg='
{
  "platform": "playflix",
  "title": "Example title",
  "description": "Platform-provided description",
  "landscape": "https://cdn.example/landscape.jpg",
  "portrait": "https://cdn.example/portrait.jpg"
}

Response fields vary by platform. Treat non-empty fields dynamically rather than assuming only title, year, landscape, and portrait exist.

GET/posters/{platform}

Call a known scraper directly. This is useful for existing integrations that already know the platform ID.

GET /posters/playflix?url=https%3A%2F%2Fwww.playflix.app%2Fcontent%2FMjAzMzg%3D

Platform IDs and accepted domains are available from /platforms.

DDL bypass

GET/bypass

Resolve a supported file-host URL to a direct download link.

Query parameterRequiredDescription
urlYesComplete HTTP(S) file-host URL.
curl -G 'https://your-api.example.com/bypass' \
  --data-urlencode 'url=https://example.com/file/abc'

GET/bypass/platforms

Return the file hosts currently supported by the direct-link resolver.

Metadata APIs

GET/tmdb

Search for a movie or TV series.

GET /tmdb?query=Inception

GET/imdb and /imdb/{imdb_id}

Search IMDb by title or ID, or fetch a title by ID.

GET /imdb?query=Inception
GET /imdb/tt1375666

GET/mydramalist and /mydramalist/{slug}

Search dramas or retrieve a drama detail page.

GET /mydramalist?query=Moving
GET /mydramalist/moving

GET/anilist/anime

Search AniList anime by query or id.

GET/anilist/anime/{anime_id}

Fetch an AniList anime by ID. The same pattern is available for /anilist/character and /anilist/manga.

GET /anilist/anime?query=One%20Piece
GET /anilist/anime/21
GET /anilist/character?id=40
GET /anilist/manga?query=Monster

Platform discovery

GET/platforms

List poster platform IDs, display names, and accepted domains.

{
  "count": 40,
  "platforms": [
    {"id":"playflix","name":"Playflix","domains":["playflix.app"]}
  ]
}

GET/supported

Open the supported-platforms HTML page.

Responses and errors

Successful JSON responses use the standard 2xx status range. Error responses contain an error or detail object.

StatusMeaning
200Request succeeded.
404Unsupported platform, missing title, or unknown resource.
502Upstream scraper or resolver failed.
500Server-side handler configuration error.
{
  "detail": {
    "error": "Unsupported platform",
    "url": "https://example.invalid/title"
  }
}
